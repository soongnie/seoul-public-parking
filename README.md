# 서울 공영주차장 탐색 대시보드

서울 공영주차장의 규모와 요금 유형을 자치구별로 비교하고,
원하는 조건의 주차장을 지도와 목록에서 탐색하는 Streamlit 대시보드입니다.

- 작성자: 박수연
- 수업: 산업데이터시각화
- 배포 앱: [https://seoul-public-parking.streamlit.app/](https://seoul-public-parking.streamlit.app/)

## 1. 분석 질문

- 자치구별로 등록된 총 주차면수는 어떻게 다른가?
- 선택한 자치구의 주차장 규모와 요금 유형은 어떻게 분포하는가?
- 원하는 요금 유형과 규모 조건에 맞는 주차장은 어디에 있는가?

## 2. 데이터 출처와 분석 대상

- 출처: 공공데이터포털 「전국주차장정보표준데이터」
- 데이터 페이지: https://www.data.go.kr/data/15012896/standard.do
- 사용 파일: `parking.csv`
- 파일 인코딩: CP949
- 분석 대상: 도로명주소 또는 지번주소가 `서울특별시`로 시작하고,
  주차장구분이 `공영`인 데이터
- 현재 사용 데이터의 분석 범위: 서울 25개 자치구, 등록 데이터 812건

812건은 서로 다른 시설의 수를 확정한 값이 아니라,
분석 조건을 충족하는 원자료의 행 수입니다.
CSV를 교체하면 집계 결과가 달라질 수 있습니다.

## 3. 데이터 처리와 집계 기준

### 주소와 자치구

주소의 앞뒤 공백을 제거하고, 도로명주소에서 자치구를 추출합니다.
도로명주소에서 추출하지 못하면 지번주소를 사용합니다.
자치구별 비교에는 자치구가 확인되는 데이터를 사용합니다.

### 주차장 규모

주차장 규모는 주차구획수, 즉 주차 칸 수를 뜻하며 단위는 면입니다.
쉼표 등을 제거한 뒤 숫자로 변환하고,
숫자로 변환할 수 없거나 음수인 값은 결측치로 처리합니다.

- 등록 건수: 원자료의 행 수
- 총 주차면수: 유효한 주차구획수의 합계
- 규모 중앙값: 유효한 주차구획수를 정렬했을 때 가운데에 해당하는 값

### 요금 유형

제공기관이 등록한 `유료`, `무료`, `혼합` 분류를 사용합니다.
그 외 값과 빈 값은 `기타·미상`으로 처리합니다.

무료 비율은 해당 자치구의 전체 등록 건수 중
`무료`로 등록된 건수의 비율이며, `혼합`은 포함하지 않습니다.

이 분류만으로 최초 무료시간이나 요일·이용 대상별 감면 조건을
확정할 수는 없습니다.

### 중복 의심 기록

관리번호가 반복된다는 이유만으로 데이터를 삭제하지 않았습니다.
동일 시설이 중복 등록되어 있다면 건수와 주차면수 합계가
실제보다 커질 수 있습니다.

### 자치구 평균 대비 배율

자치구별 지표 값을 같은 비중으로 평균 낸 뒤,
선택한 구의 값을 그 평균으로 나눕니다.

- 1배: 자치구 평균과 같음
- 0.5배: 자치구 평균의 절반
- 2배: 자치구 평균의 두 배

규모 중앙값의 비교 기준은 자치구별 중앙값의 평균이며,
무료 비율의 비교 기준은 자치구별 무료 비율의 평균입니다.
서울 전체 기록을 한꺼번에 계산한 중앙값·무료 비율과는 다를 수 있습니다.

## 4. 주요 기능과 시각화

### 상단 요약 지표

선택한 자치구의 등록 건수, 주차구획수 합계,
규모 중앙값, 무료 데이터 비율을 보여 줍니다.

### 주차장 찾기

- 요금 유형과 최소 주차구획수로 조건 설정
- 조건에 맞는 주차장의 위치를 지도에 표시
- 마우스를 올려 주차장명, 규모, 주소, 원자료 행 확인
- 조건에 맞는 데이터 중 규모 상위 10건을 가로 막대그래프로 표시

상위 10건 그래프는 원자료 행을 구분하여,
이름이 같은 기록도 각각 표시합니다.

### 서울 전체 비교

- 총 주차면수, 등록 건수, 규모 중앙값, 무료 비율을
  자치구별 가로 막대그래프로 비교
- 자치구 평균을 점선으로 표시

### 선택 지역 분석

- 도넛 차트: 요금 유형별 건수 비율
- 박스플롯: 주차장 규모의 중앙값, 퍼짐, 이상치
- 막대그래프: 선택한 자치구의 지표를 자치구 평균 대비 배율로 비교

박스플롯의 상자는 중간 50% 구간을 나타냅니다.
실선은 중앙값, 점선은 평균이며,
수염 밖의 점이 반드시 데이터 오류를 뜻하지는 않습니다.

### 데이터·한계

- 현재 필터 결과를 표로 조회
- 현재 필터 결과를 UTF-8 BOM 형식의 CSV로 다운로드
- 데이터 출처, 집계 기준, 해석의 한계 확인
- 데이터 기준일 범위 확인
- 처음 10행 미리보기와 관리번호 반복 기록 점검

`원자료행`은 CSV를 헤더 포함 표로 열었을 때
해당 기록을 찾기 위한 행 번호이며, 시설 고유번호가 아닙니다.

## 5. 필터 적용 범위

자치구 선택은 상단 요약 지표, 주차장 찾기,
선택 지역 분석, 목록·다운로드의 대상 지역을 결정합니다.
서울 전체 비교는 서울 전체 데이터를 사용합니다.

요금 유형·최소 주차구획수 필터의 적용 범위는 다음과 같습니다.

| 화면 | 요금 유형·최소 주차구획수 필터 |
|---|---|
| 상단 요약 지표 | 적용하지 않음 |
| 주차장 찾기 탭 전체 | 적용 |
| 서울 전체 비교 | 적용하지 않음 |
| 선택 지역 분석 | 적용하지 않음 |
| 데이터·한계의 목록·CSV 다운로드 | 적용 |

현재 코드에서는 규모 정보가 없는 기록이
최소 주차구획수 조건을 통과하지 못하므로,
최솟값을 0으로 설정해도 필터 결과에서 제외됩니다.

## 6. 실행 방법

Python 3.13 환경을 기준으로 합니다.

다음 네 파일을 같은 폴더에 둡니다.

- `app.py`: 대시보드 실행 코드
- `parking.csv`: 분석에 사용하는 전국 주차장 CSV
- `requirements.txt`: 필요한 Python 패키지
- `README.md`: 프로젝트 설명

해당 폴더에서 터미널을 열고 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

데이터를 다른 이름으로 다운로드했다면
파일명을 `parking.csv`로 변경해야 합니다.

## 7. 배포 방법

GitHub 저장소에 위 파일을 업로드한 후,
Streamlit Community Cloud에서 해당 저장소를 연결합니다.

- 시작 파일: `app.py`
- Python 버전: 3.13
- 데이터 파일: `app.py`와 같은 폴더의 `parking.csv`

CSV 파일을 직접 읽는 방식이므로
공공데이터 API 활용 신청이나 API 키는 필요하지 않습니다.
지도 배경을 불러오려면 인터넷 연결이 필요합니다.

## 8. 해석의 한계

- 등록 건수는 원자료 행 수이며, 실제로 서로 다른 시설의 수와 다를 수 있습니다.
- 중복 등록, 지역별 자료 누락, 갱신 시점 차이가 있을 수 있습니다.
- 등록 건수가 적은 구는 일부 기록만으로 비율이 크게 달라질 수 있습니다.
- 인구, 차량 수, 주차 수요를 반영하지 않았으므로,
  주차면수가 많다는 이유만으로 주차 공간이 충분하다고 판단할 수 없습니다.
- 실시간 빈자리와 혼잡도는 제공하지 않습니다.
- 지도는 좌표 유효성 검사를 통과한 기록만 표시합니다.
  좌표 검사를 통과하더라도 실제 위치의 정확성을 보장하지 않으며,
  동일 좌표의 점은 겹칠 수 있습니다.
- 요금 유형만으로 실제 결제 금액이나 무료 이용 조건을 확정할 수 없습니다.
- 데이터 기준일은 각 기록의 정보 기준 날짜이며,
  분석 기간이나 파일 다운로드 날짜를 의미하지 않습니다.
