# 서울 공영주차장 탐색 대시보드

서울 공영주차장의 등록 주차면수를 자치구별로 비교하고, 선택한 자치구의 규모 분포와 요금 유형을 살펴보는 Streamlit 대시보드입니다. 원하는 요금 유형과 규모 조건에 맞는 주차장을 지도와 목록에서 탐색할 수 있습니다.

- 작성자: 박수연
- 수업: 산업데이터시각화
- 배포 앱: https://seoul-public-parking.streamlit.app/
- 발표 제목: 서울 공영주차장 데이터 탐색 — 자치구별 주차면수 비교와 동대문구 사례 분석

## 1. 주제 선정 동기와 분석 질문

서울의 맛집이나 카페를 자차로 방문할 때, 전용 주차장이 없거나 작은 골목에 위치해 있으면 주차할 곳을 찾기 어려울 수 있습니다. 주변 공영주차장의 위치뿐 아니라 규모와 요금 유형을 함께 확인하고, 방문 전 주차장 후보를 좁힐 수 있도록 대시보드를 제작했습니다.

### 분석 질문

1. 어느 자치구에 주차면수가 많이 등록되어 있을까?
2. 선택한 자치구의 주차장 규모와 요금 유형은 어떻게 분포할까?
3. 원하는 요금 유형과 규모 조건에 맞는 주차장은 어디에 있을까?

대시보드에서는 자치구를 선택해 탐색할 수 있습니다. 발표에서는 서울 25개 자치구의 등록 주차면수를 비교한 뒤, 동대문구를 사례로 규모 분포와 요금 유형을 분석했습니다. 동대문구의 결과를 서울 전체의 특성으로 일반화하지 않습니다.

## 2. 데이터 출처와 분석 대상

- 출처: 공공데이터포털 「전국주차장정보표준데이터」
- 데이터 페이지: https://www.data.go.kr/data/15012896/standard.do
- 사용 파일: `parking.csv`
- 파일 인코딩: CP949
- 분석 대상: 도로명주소 또는 지번주소가 `서울특별시`로 시작하고, 주차장구분이 `공영`인 데이터
- 발표에 사용한 데이터: 서울 25개 자치구, 등록 기록 812건
- 동대문구 사례 분석: 등록 기록 22건

812건은 서로 다른 시설의 수를 확정한 값이 아니라, 분석 조건을 충족하는 원자료의 행 수입니다. CSV를 교체하면 집계 결과가 달라질 수 있습니다.

## 3. 데이터 처리와 집계 기준

### 주소와 자치구

주소의 앞뒤 공백을 제거하고, 도로명주소에서 자치구를 추출합니다. 도로명주소에서 추출하지 못하면 지번주소를 사용합니다.

자치구별 비교에는 자치구를 확인할 수 있는 데이터를 사용합니다.

### 주차장 규모

주차장 규모는 주차구획수, 즉 주차 칸 수를 뜻하며 단위는 `면`입니다. 쉼표 등을 제거한 뒤 숫자로 변환하고, 숫자로 변환할 수 없거나 음수인 값은 결측치로 처리합니다.

- 등록 건수: 원자료의 행 수
- 총 주차면수: 유효한 주차구획수의 합계
- 규모 중앙값: 유효한 주차구획수를 정렬했을 때 가운데에 해당하는 값
- 규모 평균: 유효한 주차구획수의 합을 해당 기록 수로 나눈 값

### 요금 유형

제공기관이 등록한 `유료`, `무료`, `혼합` 분류를 사용합니다. 그 외 값과 빈 값은 `기타·미상`으로 처리합니다.

무료 비율은 해당 자치구의 전체 등록 건수 중 `무료`로 등록된 건수의 비율이며, `혼합`은 포함하지 않습니다.

요금 유형만으로 최초 무료시간, 요일별 운영, 이용 대상별 감면 조건이나 실제 결제 금액을 확정할 수는 없습니다. 실제 이용 조건은 운영기관 안내를 확인해야 합니다.

### 중복 의심 기록

관리번호가 반복된다는 이유만으로 데이터를 삭제하지 않았습니다. 관리번호 반복이 반드시 동일 시설의 중복을 의미하지는 않기 때문입니다.

다만 동일 시설이 중복 등록되어 있다면 건수와 주차면수 합계가 실제보다 커질 수 있습니다.

### 자치구 평균 대비 배율

자치구별 지표 값을 같은 비중으로 평균 낸 뒤, 선택한 구의 값을 그 평균으로 나눕니다.

- 1배: 자치구 평균과 같음
- 0.5배: 자치구 평균의 절반
- 2배: 자치구 평균의 두 배

규모 중앙값의 비교 기준은 자치구별 중앙값의 평균이며, 무료 비율의 비교 기준은 자치구별 무료 비율의 평균입니다. 각각 서울 전체 기록을 한꺼번에 계산한 중앙값·무료 비율과는 다를 수 있습니다.

## 4. 주요 기능과 시각화

### 상단 요약 지표

선택한 자치구의 등록 건수, 주차구획수 합계, 규모 중앙값, 무료 데이터 비율을 보여 줍니다.

### 주차장 찾기

- 요금 유형과 최소 주차구획수로 조건 설정
- 조건에 맞는 기록 중 유효한 좌표가 있는 기록을 지도에 표시
- 툴팁으로 주차장명, 규모, 주소, 원자료 행 확인
- 조건에 맞는 데이터 중 규모 상위 10건을 가로 막대그래프로 표시

상위 10건 그래프는 원자료 행을 구분하여, 이름이 같은 기록도 각각 표시합니다. 조건에 맞는 기록이 10건보다 적으면 해당 기록만 표시합니다.

지도와 규모 정보는 주차장 후보를 탐색하기 위한 정보이며, 실시간 빈자리를 뜻하지 않습니다.

### 서울 전체 비교

- 총 주차면수, 등록 건수, 규모 중앙값, 무료 비율을 자치구별 가로 막대그래프로 비교
- 선택한 자치구를 다른 색으로 강조
- 자치구 평균을 점선으로 표시

가로 막대그래프는 공통 축에서 자치구별 지표의 크기와 순위를 비교하는 데 사용합니다.

### 선택 지역 분석

- 도넛 차트: 선택한 자치구 전체 등록 기록의 요금 유형별 건수 비율
- 박스플롯: 주차장 규모의 중앙값·평균·중간 50% 구간과 경계 밖의 값
- 막대그래프: 선택한 자치구의 지표를 자치구 평균 대비 배율로 비교

#### 박스플롯의 계산과 표시

사분위수는 pandas로 계산하며, 동일한 값을 상자·수염·경계선 계산과 설명에 사용합니다.

- 상자: 제1사분위수(Q1)부터 제3사분위수(Q3)까지의 중간 50% 구간
- 상자 안의 실선: 중앙값
- 상자 안의 점선: 평균
- 사분위범위(IQR): Q3−Q1
- 주황색 파선: 하한 경계(Q1−1.5×IQR)와 상한 경계(Q3+1.5×IQR)
- 수염 끝: 두 경계 안에 있는 실제 데이터의 최솟값과 최댓값
- 별도의 점: 경계를 벗어난 기록

수염 끝과 계산한 경계선은 일치하지 않을 수 있습니다. 경계 밖의 기록은 규모가 크거나 작다는 이유만으로 오류로 단정해 삭제하지 않았습니다.

하한 경계는 계산상 음수가 될 수 있으며, 실제 주차구획수가 음수라는 뜻은 아닙니다.

### 데이터·한계

- 현재 필터 결과를 표로 조회
- 현재 필터 결과를 UTF-8 BOM이 포함된 CSV로 다운로드
- 데이터 출처, 집계 기준, 해석의 한계 확인
- 선택한 자치구의 데이터 기준일 범위 확인
- 서울 공영주차장 데이터의 처음 10행 미리보기
- 관리번호가 반복되는 기록 점검

`원자료행`은 CSV를 헤더 포함 표로 열었을 때 해당 기록을 찾기 위한 행 번호이며, 시설 고유번호가 아닙니다.

## 5. 필터 적용 범위

자치구 선택은 상단 요약 지표, 주차장 찾기, 선택 지역 분석, 목록·다운로드의 대상 지역을 결정합니다. 서울 전체 비교는 서울 전체 데이터를 사용하며, 선택한 자치구를 강조합니다.

요금 유형·최소 주차구획수 필터의 적용 범위는 다음과 같습니다.

| 화면 | 요금 유형·최소 주차구획수 필터 |
|---|---|
| 상단 요약 지표 | 적용하지 않음 |
| 주차장 찾기 탭 전체 | 적용 |
| 서울 전체 비교 | 적용하지 않음 |
| 선택 지역 분석 | 적용하지 않음 |
| 데이터·한계의 목록·CSV 다운로드 | 적용 |

현재 코드에서는 규모 정보가 없는 기록이 최소 주차구획수 조건을 통과하지 못하므로, 최소 주차구획수를 0으로 설정해도 필터 결과에서 제외됩니다.

## 6. 발표의 주요 분석 결과

아래 결과는 발표에 사용한 CSV의 등록 기록 기준입니다.

### 자치구별 등록 주차면수

강남구 6,660면, 양천구 5,303면, 서초구 5,156면 순으로 많았습니다. 동대문구는 1,385면으로 자치구 평균보다 낮았습니다.

이는 등록된 주차구획수 합계의 비교이며, 실제 빈자리나 주차 공간의 충분함을 나타내지는 않습니다.

### 동대문구의 규모 분포

등록 기록 22건의 규모 중앙값은 55.5면, 평균은 약 63.0면입니다. 최솟값은 13면, 최댓값은 196면이며, 중간 50% 구간은 약 40.5~75.8면입니다.

143면과 196면의 큰 기록은 상한 경계를 벗어나며, 이러한 큰 값들이 평균을 높입니다. 따라서 전형적인 규모를 설명할 때 평균과 중앙값을 함께 살펴볼 필요가 있습니다.

### 동대문구의 요금 유형

- 유료: 12건(54.5%)
- 혼합: 10건(45.5%)
- 무료: 0건

무료로 등록된 기록이 없다는 사실이 모든 기록에 무료 이용 조건이 없다는 뜻은 아닙니다. 요금 유형의 구성과 실제 이용 요금은 구분해서 해석해야 합니다.

### 조건별 지도 탐색

동대문구에서 요금 유형을 모두 선택하고 최소 주차구획수를 100면으로 설정하면, 143면과 196면의 기록 두 건을 확인할 수 있습니다.

박스플롯에서 확인한 큰 규모의 기록을 지도·툴팁·목록으로 연결하여 위치와 상세 정보를 탐색할 수 있습니다.

## 7. 해석의 한계

### 중복 등록 가능성

동일 시설이 여러 번 등록됐다면 건수와 주차면수 합계가 실제보다 커질 수 있습니다. 등록 건수를 실제로 서로 다른 시설의 수로 단정할 수 없습니다.

### 자료 누락·기준일 차이

자치구별 자료에 누락이 있을 수 있고, 기록마다 기준일이 달라 실제 전체 현황과 차이가 있을 수 있습니다.

특히 등록 건수가 적은 구는 일부 기록만으로 비율이 크게 달라질 수 있습니다. 등록 데이터의 순위를 실제 전체 주차장 현황의 순위로 단정할 수 없습니다.

데이터 기준일은 각 기록의 정보 기준 날짜이며, 분석 기간이나 파일 다운로드 날짜를 의미하지 않습니다.

### 실제 이용 상황 미반영

주차 수요, 실시간 빈자리, 혼잡도와 세부 요금 조건은 분석에 반영하지 않았습니다.

주차 수요는 해당 지역에서 주차하려는 차량의 수요를 뜻합니다. 주차면수가 많다는 이유만으로 주차 공간이 충분하거나 실제 주차하기 편하다고 판단할 수 없습니다.

요금 유형만으로 실제 결제 금액이나 무료 이용 조건을 확정할 수도 없습니다.

### 지도 좌표의 한계

지도는 위도·경도가 숫자로 확인되고, 좌표 범위 검사와 0 좌표 제외 조건을 통과한 기록만 표시합니다.

좌표 검사를 통과하더라도 실제 위치의 정확성을 보장하지 않으며, 동일 좌표의 점은 겹칠 수 있습니다.

이 대시보드는 지역별 등록 현황을 비교하고 방문 전 주차장 후보를 좁히는 데 활용할 수 있습니다. 실제 이용 가능 여부와 요금은 운영기관 안내를 별도로 확인해야 합니다.

## 8. 실행 방법

Python 3.13 환경을 기준으로 합니다.

다음 네 파일을 같은 폴더에 둡니다.

- `app.py`: 대시보드 실행 코드
- `parking.csv`: 분석에 사용하는 전국 주차장 CSV
- `requirements.txt`: 필요한 Python 패키지
- `README.md`: 프로젝트 설명

해당 폴더에서 터미널을 열고 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

데이터를 다른 이름으로 다운로드했다면 파일명을 `parking.csv`로 변경해야 합니다.

- 데이터 파일: `app.py`와 같은 폴더의 `parking.csv`
- 패키지 설치 목록: `requirements.txt`

CSV 파일을 직접 읽는 방식이므로 공공데이터 API 활용 신청이나 API 키는 사용하지 않습니다. 지도 배경을 불러오려면 인터넷 연결이 필요합니다.
